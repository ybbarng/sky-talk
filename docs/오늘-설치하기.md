# 오늘 설치하기

> 내일이 여행이다. 이 문서만 따라 하면 된다.

## 1. 안드로이드 (내 폰)

```bash
pnpm build:android
```

이 명령 하나가 아이콘을 만들고, JDK 17 로 **릴리스** 빌드를 하고, 폰에 설치까지 한다. 5~10분 걸린다.

### 반드시 릴리스여야 하는 이유

| | 개발 빌드 | 릴리스 빌드 |
|---|---|---|
| 명령 | `pnpm dev:android` | `pnpm build:android` |
| 앱을 열려면 | **맥에서 번들러가 돌아야 한다** | 혼자 돈다 |
| 비행기에서 | **안 열린다** | 열린다 |

개발 빌드는 코드를 고칠 때만 쓴다. 비행기에 가져갈 것은 반드시 릴리스다.

### 막히면

**`Gradle requires JVM 17`** — `JAVA_HOME` 이 JDK 11 을 가리키고 있다. `pnpm build:android` 는 알아서 17 을 쓰므로 이 명령을 쓰면 된다. 직접 `./gradlew` 를 쓸 거면 앞에 붙인다.

```bash
JAVA_HOME=$(/usr/libexec/java_home -v 17) ./gradlew assembleRelease
```

**폰이 안 잡힌다** — USB 연결 후 폰에서 **개발자 옵션 → USB 디버깅**을 켜고, "이 컴퓨터를 허용"을 누른다.

```bash
adb devices     # 폰이 목록에 떠야 한다
```

## 2. 아이폰 (여자친구 폰)

**아이폰이 맥에 USB 로 연결돼 있어야 한다.**

```bash
pnpm dev:ios
```

설치된 뒤 **아이폰에서 한 번 더 해야 한다.**

```
설정 → 일반 → VPN 및 기기 관리 → 개발자 앱 → 신뢰
```

**이걸 빠뜨리면 앱이 안 열린다.** 처음 한 번만 하면 된다.

### 7일 문제

유료 개발자 계정이 없어서 **아이폰 앱은 7일 뒤 열리지 않는다.**

- 오늘 깔면 **7일 뒤**까지다
- 여행이 그보다 길면 중간에 앱이 죽는다
- 그때는 맥이 있어야 다시 깔 수 있다

여행이 일주일을 넘으면 **맥을 가져가거나**, 대화가 중요하면 안드로이드 쪽에만 기록이 쌓이게 두고 나중에 꺼낸다.

## 3. 핫스팟 맞춰두기

앱이 어느 핫스팟을 찾을지는 `.env` 에 적는다. 저장소가 공개라
비밀번호를 코드에 두지 않는다.

```bash
cp .env.example .env
```

열어서 내 핫스팟 이름과 비밀번호를 채운다.

```
EXPO_PUBLIC_HOTSPOT_SSID=내-핫스팟-이름
EXPO_PUBLIC_HOTSPOT_PASSWORD=비밀번호
```

**채운 뒤에 빌드해야 한다.** 값은 빌드할 때 앱 안에 박히므로, 나중에
바꾸면 다시 빌드해야 한다. (그래서 앱 파일을 뜯으면 보인다. 저장소에
안 올라가는 것까지가 여기서 얻는 것이다.)

여자친구 폰 화면에 이 이름과 비밀번호가 그대로 떠서, 물어보지 않고도
어디로 들어가야 할지 알 수 있다. **안 채워도 앱은 돌아간다.** 이름을
알려주는 안내만 빠지고, 예전처럼 내 화면을 보여줘야 한다.

핫스팟 이름을 바꾸려면 `설정 → 연결 → 모바일 핫스팟 및 테더링 →
모바일 핫스팟` 으로 들어간다.

### 설정 메뉴 어디에 있나

삼성 폰은 `네트워크 및 인터넷` 이 아니라 **`연결`** 아래다.
픽셀 같은 순정 안드로이드와 다르다.

| | 한국어 | 프랑스어 |
|---|---|---|
| 안드로이드 | 설정 → 연결 → 모바일 핫스팟 및 테더링 | Paramètres → Connexions → Point d'accès mobile et modem |
| 아이폰 핫스팟 | 설정 → 개인용 핫스팟 | Réglages → Partage de connexion |
| 아이폰 Wi-Fi | 설정 → Wi-Fi | Réglages → Wi-Fi |
| 비행기 모드 | 비행기 모드 | Mode Avion |

**빠른 설정 패널에 핫스팟 타일을 올려둔다.** 위에서 두 번 쓸어내려
타일 편집으로 들어가 `모바일 핫스팟` 을 위쪽으로 끌어둔다. 비행기에서
비행기 모드를 켠 뒤 핫스팟을 다시 켜야 하는데, 그때 설정을 헤매지 않는다.

## 4. 처음 켜서 이어보기

두 폰 다 앱을 연 뒤:

### 내 폰 (안드로이드)

1. 앱이 "내 폰으로 이어줄게요" 라고 한다
2. **핫스팟 켜러 가기** 를 누른다 → 설정에서 핫스팟을 켠다
3. 앱으로 돌아오면 "준비됐어요" 로 바뀐다
4. **핫스팟 이름과 비밀번호를 여자친구에게 보여준다**

### 여자친구 폰 (아이폰)

1. 앱이 **"Wi-Fi 에 들어가면 돼요"** 라며 핫스팟 이름을 화면에 띄운다
2. 비밀번호도 같이 떠 있다. **길게 누르면 복사된다**
3. **Wi-Fi 고르러 가기** 를 누른다 → 그 이름을 고르고 비밀번호를 붙여넣는다
4. 앱으로 돌아오면 알아서 찾는다
5. 찾으면 캐릭터가 또렷해지며 "찾았어요" 가 뜬다

**이름을 물어볼 일도, 주소를 입력할 일도 없다.** 앱이 이미 알고 있다.
그래도 안 되면 20초쯤 뒤에 도움말이 뜬다.

## 5. 오늘 꼭 확인할 것

집에서 해봐야 내일 안 당황한다.

```
□ 두 폰에 앱이 깔리고 열린다
□ 알림을 허용했다 (안 하면 폰을 잠갔을 때 말이 안 온다)
□ .env 를 채우고 빌드했고, 아이폰 화면에 핫스팟 이름이 뜬다
□ 핫스팟을 껐을 때 두 폰 다 "꺼져 있어요" 라고 알려준다
□ 핫스팟을 켜고 아이폰이 붙는다
□ 글이 오간다 (양쪽 다)
□ 비행기 모드로 두 폰 다 바꿔도 된다     ← 가장 중요
□ 앱을 껐다 켜도 대화가 남아 있다
□ 한쪽 앱을 껐다 켜면 알아서 다시 붙는다
□ 끊긴 동안 보낸 말이 다시 붙을 때 도착한다
```

**비행기 모드 확인을 빠뜨리지 않는다.** 집에서 잘 되던 것이 비행기 모드에서 안 되는 경우가 있다.

## 6. 비행기에서

### 탑승 전, 같이 있을 때 한 번 이어둔다

**이게 핵심이다.** 떨어져 앉으면 화면을 보여줄 수 없다.

한 번 붙여두면 **여자친구 폰이 핫스팟 이름과 비밀번호를 기억한다.** 자리에서는
비밀번호를 다시 넣을 일이 없다.

### 자리에 앉은 뒤

| | 내 폰 (안드로이드) | 여자친구 폰 (아이폰) |
|---|---|---|
| 1 | 비행기 모드 켜기 | 비행기 모드 켜기 |
| 2 | Wi-Fi 켜기 | **Wi-Fi 켜기 — 여기까지만** |
| 3 | **핫스팟 다시 켜기** | (알아서 들어간다) |

비행기 모드를 켜면 핫스팟이 꺼진다. **내가 다시 켜야 한다.**

앱이 이걸 알아챈다. 핫스팟이 꺼져 있으면 내 화면에 **"핫스팟이 꺼져 있어요"**
와 켜러 가는 버튼이 뜨고, 여자친구 화면에는 **"곧 다시 켜질 거예요"** 라고
떠서 자기가 뭘 잘못한 게 아니라는 걸 알 수 있다.

다행히 **여자친구가 할 일은 Wi-Fi 켜기 하나뿐이다.** 설명할 수 없는 상황에서
손이 덜 가는 쪽이 여자친구라 다행이다.

### 알아둘 것

- **핫스팟을 켠 폰은 기내 Wi-Fi 에 못 붙는다.** Wi-Fi 는 한 번에 하나만 된다.
  기내 메뉴판 같은 걸 보려면 잠깐 옮겼다 오면 되고, 돌아오면 앱이 알아서
  다시 붙는다. 그 사이 상대가 보낸 말도 되찾아 온다
- 끊겨도 알아서 다시 붙는다. 끊긴 동안 쓴 말은 사라지지 않는다
- **배터리를 넉넉히 준비한다.** 핫스팟을 켠 안드로이드가 더 빨리 준다

## 7. 아이폰 앱이 죽었을 때

**설치 없이 사파리로 들어올 수 있다.**

여자친구 폰에서 사파리를 열고 주소창에 이렇게 친다.

```
http://192.168.43.1:51705
```

내 핫스팟에 붙어 있으면 대화 화면이 그대로 뜬다. 여기서 주고받은 말도
**내 폰에 똑같이 저장돼서** 나중에 꺼내기에 같이 나온다.

주소가 안 열리면 내 폰에서 `설정 → 연결 → 모바일 핫스팟`에 들어가
"접속된 기기"를 눌러 내 주소를 확인한다. 삼성은 대개 `192.168.43.1`이다.

글자만 된다. 사진·이모티콘·통화는 앱에서만 된다. 그래도 **말이 통하는
것과 안 통하는 것의 차이**라 없는 것보다 훨씬 낫다.

## 8. 나중에 대화 꺼내기

앱 안에 SQLite 로 쌓인다. 맥에 연결해서 꺼낼 수 있다.

```bash
adb exec-out run-as com.ybbarng.skytalk cat databases/skytalk.db > 대화.db
```

`sqlite3 대화.db "SELECT * FROM messages ORDER BY received_at"` 로 읽는다.

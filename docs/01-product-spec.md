# 제품 명세 — Skywalkie

> 상태: 확정 · 최종 수정 2026-09-17

## 1. 이 앱은 무엇인가

비행기에서 떨어져 앉은 두 사람이 **인터넷 없이** 서로 메시지를 주고받고, 목소리로 이야기하고, 얼굴을 보는 앱이다.

기내 Wi-Fi를 사거나 승무원을 부르지 않고, 두 사람의 휴대폰만으로 둘만의 통신망을 만든다.

### 제품 이름

- 표시 이름: **Skywalkie** (한국어 화면에서는 "스카이워키")
- 패키지 식별자: `com.ybbarng.skywalkie`
- 폴더 이름은 `walkie-talkie`로 두되 앱 이름만 Skywalkie로 쓴다.

### 쓰는 사람

정확히 두 명이다. 그룹 채팅도, 친구 추가도, 회원 가입도 없다.

| | 사람 A | 사람 B |
|---|---|---|
| 기기 | 안드로이드 폰 | 아이폰 |
| 이어폰 | 갤럭시 버즈 프로 | 에어팟 프로, 무선 헤드폰 |
| 역할 | 무선망을 여는 쪽(호스트) | 접속하는 쪽(게스트) |

둘 다 앱을 처음 쓴다. **서로 말을 할 수 없는 상황에서 각자 화면만 보고 연결에 성공해야 한다.** 이게 이 앱의 가장 중요한 요구사항이다.

## 2. 꼭 되어야 하는 것

### F1. 두 기기가 서로 찾아 연결된다

- 안드로이드가 핫스팟을 열고 아이폰이 붙으면, 앱이 **상대를 자동으로 찾아** 연결한다. IP 주소를 손으로 입력하는 일은 없다.
- 자동 탐색이 실패하면 잠시 뒤 스스로 다시 찾는다. 사람이 코드나 주소를 읽어주는 일은 없다(예전의 여섯 자리 코드 기능은 없앴다).
- 연결이 끊기면 스스로 다시 붙는다. 사용자가 뭘 누를 필요 없다.
- 연결 상태(연결됨 / 찾는 중 / 끊김)가 화면에 늘 보인다.

### F2. 메시지를 주고받고 기기에 남는다

- 텍스트 메시지를 주고받는다. 카카오톡을 대신하는 자리다.
- 메시지는 **각자의 기기에 저장**되어 비행기에서 내린 뒤에도 다시 볼 수 있다.
- 연결이 끊긴 동안 보낸 메시지는 대기하다가 다시 붙으면 자동으로 전달된다.
- 보냄 / 전달됨 / 읽음 상태가 보인다.
- 상대가 입력 중이면 표시된다.

### F2-1. 대화와 데이터를 꺼내서 보관할 수 있다

앱이 사라져도 대화는 남아야 한다. 아이폰 앱이 7일마다 만료되는 조건에서 이건 부가 기능이 아니라 필수다.

- **통째로 내보내기**: 대화 전체, 설정, 캐릭터 선택을 하나의 파일로 묶어 내보낸다. 내보낸 파일은 사진 앱·파일 앱·메일·에어드롭 등 기기가 제공하는 아무 경로로나 보낼 수 있다.
- **읽을 수 있는 형태로 내보내기**: 나중에 앱 없이도 읽도록 사람이 읽는 형식으로도 내보낸다. 날짜별로 정리된 텍스트 파일과, 그대로 열어볼 수 있는 HTML 파일 두 가지를 만든다.
- **되돌리기**: 내보낸 파일을 다시 불러오면 대화가 그대로 복원된다. 재설치한 아이폰에서도 마찬가지다.
- **중복 없이 합치기**: 불러온 대화와 기기에 이미 있는 대화가 겹쳐도 같은 메시지가 두 번 쌓이지 않는다. 메시지마다 고유한 식별자를 두어 판단한다.
- **자동 보관**: 앱이 뒤로 갈 때마다 최근 대화를 기기 안 별도 위치에 자동으로 복사해 둔다. 사용자가 잊어도 최소 하루치는 살아남는다.
- **누락 없음 확인**: 내보낼 때 메시지 개수와 검증값을 같이 적어두고, 불러올 때 대조해 빠진 게 있으면 알린다.

자세한 형식과 절차는 [05-messaging-spec.md](./05-messaging-spec.md)의 "보관과 내보내기" 항목에 적는다.

### F3. 음악을 들으면서도 목소리로 대화한다

- 음악이나 영화 소리를 **끄지 않고** 상대 목소리를 듣는다. 상대가 말하면 음악이 자동으로 작아지고(더킹), 말이 끝나면 원래대로 돌아온다.
- 두 가지 말하기 방식을 **둘 다** 지원한다.
  - **누르고 말하기**: 버튼을 누르는 동안만 마이크가 켜진다. 배터리와 사생활에 유리하다.
  - **항상 열기**: 마이크가 계속 열려 있어 전화처럼 대화한다. 소리가 없을 땐 알아서 전송을 멈춘다.
- 화면을 끄거나 다른 앱을 써도 대화가 유지된다.
- 이어폰을 꼈다 뺐다 해도 소리가 엉키지 않는다.

### F4. 처음 쓰는 사람이 설명 없이 쓸 수 있다

- 첫 실행 때 **역할을 고르는 화면**이 나오고, 고른 역할에 맞는 단계별 안내가 그림과 함께 뜬다.
- 화면의 모든 버튼 옆에 **물음표**가 있어 누르면 "이게 뭐 하는 건지" 한두 줄로 설명한다.
- 문제가 생기면 "무엇이 잘못됐고 무엇을 누르면 되는지"를 한국어로 알려준다. 오류 코드만 띄우지 않는다.

### F5. 밝은 화면과 어두운 화면을 모두 지원한다

- 기기 설정을 따라가되, 앱 안에서 따로 고를 수도 있다.
- 기내는 어둡다. 어두운 화면이 기본에 가깝게 잘 다듬는다.

### F6. 서로의 캐릭터가 보인다

- 첫 실행 때 자기 캐릭터를 고른다. 상대 화면에는 내 캐릭터가, 내 화면에는 상대 캐릭터가 뜬다.
- 기본값: 안드로이드 쪽(남성) 화면에는 여성 캐릭터가, 아이폰 쪽(여성) 화면에는 남성 캐릭터가 상대로 표시된다.
- 캐릭터는 그림 파일이 아니라 **코드로 그리는 벡터**라서 어떤 화면 크기에서도 선명하고, 밝은/어두운 화면에 맞춰 색이 바뀐다.
- 캐릭터는 가만히 있지 않는다. 상대가 말하면 입이 움직이고, 연결이 끊기면 시무룩해진다.

## 3. 되면 좋은 것

### F7. 영상 통화

- 얼굴을 보며 이야기한다. 화질은 통신 상태에 맞춰 알아서 낮춘다.
- 앞뒤 카메라를 바꿀 수 있고, 영상만 잠시 끌 수도 있다.

### F8. 비상용 웹 채팅

- 아이폰 앱은 7일 뒤 열리지 않는다(9번 제약 참고). 그때를 위해 안드로이드 앱이 작은 웹 서버를 띄운다.
- 아이폰은 사파리로 들어와 **설치 없이** 텍스트 채팅만 할 수 있다.
- 음성·영상은 안 된다. 브라우저가 인터넷 없는 환경에서 마이크를 열어주지 않기 때문이다.

### F9. 사진 주고받기

> 기본 기능을 다 만든 뒤에 붙인다.

- 앨범에서 고르거나 그 자리에서 찍어 보낸다. 기내에서 창밖이나 기내식을 찍어 보내는 용도다.
- **보내기 전에 줄인다.** 긴 변을 1600픽셀로 맞추고 JPEG로 다시 저장한다. 원본을 그대로 보내면 몇 MB짜리가 사설망을 막는다.
- 원본을 보낼지 고를 수 있게 한다. 다만 시간이 걸린다고 미리 알린다.
- 큰 파일이므로 **조각내어 보내고 진행률을 보여준다.** 도중에 끊기면 받은 데까지 기억했다가 이어서 받는다.
- 사진은 기기 안 앱 폴더에 저장되고 대화 기록에 함께 들어간다. 내보내기에도 포함된다.
- **블루투스로 연결됐을 땐 보내지 않는다.** 대기시켜 두었다가 Wi-Fi가 열리면 내보낸다.

### F10. 이모지와 이모티콘

> 기본 기능을 다 만든 뒤에 붙인다.

- 자주 쓰는 이모지를 한 줄로 띄워 바로 누를 수 있게 한다.
- 메시지를 꾹 누르면 **이모지로 반응**을 붙인다. 짧은 대답에 말풍선을 새로 만들지 않아도 된다.
- 앱에서 만든 **캐릭터 이모티콘**을 넣는다. 각자 고른 캐릭터가 손을 흔들거나 자거나 하트를 띄우는 그림이다. 캐릭터와 같은 방식으로 코드로 그려서 앱 크기가 늘지 않는다.
- 이모티콘만 보내면 말풍선 없이 크게 보인다.

### F11. 둘이서 할 만한 것들

기내에서 열 시간을 같이 보내는 장치다.

- **같이 보기**: 지금 듣는 노래나 보는 영화를 서로에게 알린다.
- **콕 찌르기**: 한 번 누르면 상대 폰이 짧게 진동한다. 말 없이 "자니?" 하는 용도다.
- **낙서 주고받기**: 손가락으로 그린 그림을 보낸다.
- **남은 시간**: 목적지 도착까지 남은 시간을 둘이 같은 화면으로 본다.
- **질문 카드**: "지금 제일 하고 싶은 거"처럼 둘이 답할 질문이 한 장씩 나온다.

## 4. 만들지 않는 것

경계를 분명히 해둔다.

- 셋 이상이 참여하는 대화
- 인터넷을 거치는 통신, 계정, 서버
- 메시지가 다른 기기로 동기화되는 기능
- 사진 외의 파일 전송 (문서, 음악 파일 등)
- 동영상 전송 (너무 크다. 영상은 통화로만)
- 안드로이드끼리 또는 아이폰끼리의 연결 (한쪽이 반드시 호스트)

## 5. 반드시 지켜야 하는 제약

### C1. 인터넷이 없다

외부 서버에 의존하는 설계는 전부 쓸 수 없다. 로그인, 푸시 알림, STUN/TURN 서버, 원격 설정, 오류 수집 서비스 모두 안 된다.

### C2. 아이폰 앱은 7일마다 다시 설치해야 한다

유료 개발자 계정이 없어 무료 계정으로 서명한다. 7일이 지나면 앱이 열리지 않는다.

- 여행 **출발 하루 전**에 다시 설치해야 한다.
- 저장된 메시지는 재설치해도 지워지지 않도록 만든다. (기기 내부 저장소는 앱 삭제 시 지워지므로, 앱을 지우지 않고 **덮어쓰기**로 다시 설치하는 절차를 안내한다.)
- 덮어쓰기가 안 되는 상황에 대비해 F2-1의 내보내기·되돌리기가 항상 동작해야 한다. **앱 만료 안내 화면에서 내보내기 버튼을 바로 누를 수 있게** 배치한다.
- 만료 3일 전부터 앱이 먼저 알린다. "곧 이 앱이 열리지 않습니다. 대화를 내보내 두세요."

### C3. 항공사가 핫스팟을 금지할 수 있다

비행기 모드에서 Wi-Fi를 켜는 것은 대부분 허용되지만, 개인 핫스팟은 금지하는 항공사가 있다. 그래서 **블루투스만으로 텍스트를 주고받는 보조 경로**를 반드시 만든다.

### C4. 배터리

비행 시간 내내 켜둘 수 있어야 한다. 화면을 끈 채 대기할 때 전력을 아끼는 설계를 기본으로 한다.

### C5. 개인정보

모든 데이터는 두 기기 밖으로 나가지 않는다. 사용 기록을 수집하는 코드를 넣지 않는다.

## 6. 잘 만들었는지 판단하는 기준

| 기준 | 목표 |
|---|---|
| 처음 켜서 연결까지 | 안내만 보고 3분 안에 |
| 메시지 전달 지연 | 0.3초 이내 |
| 목소리 지연 | 0.4초 이내 |
| 음악을 들으며 대화 | 음악이 끊기지 않고 목소리가 또렷하게 들린다 |
| 연결이 끊겼다 붙기까지 | 10초 이내 자동 복구 |
| 대기 상태 배터리 | 시간당 5% 이내 |
| 놓치는 메시지 | 0건 (끊긴 동안 보낸 것도 전부 도착) |
| 내보내고 되돌리기 | 만 건을 내보내고 다시 불러도 하나도 빠지거나 겹치지 않는다 |

## 7. 화면 구성

```
첫 실행
  └ 환영 → 역할 고르기 → 캐릭터 고르기 → 연결 안내 → 권한 요청

주 화면 (아래 탭 3개)
  ├ 대화       메시지 주고받기, 낙서, 콕 찌르기
  ├ 통화       누르고 말하기 / 항상 열기, 영상 통화
  └ 설정       연결 상태, 화면 밝기 모드, 대화 내보내기, 도움말
```

연결 상태는 탭과 무관하게 화면 맨 위에 늘 붙어 있다.

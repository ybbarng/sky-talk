# 제품 명세 — SkyTalk

> 상태: 확정 · 최종 수정 2026-09-19

## 0. 2026-09-19 에 무엇이 바뀌었나

비행 전날 두 폰으로 끝까지 써보며 문서와 앱을 맞췄다. 큰 줄기만 적는다.

- **블루투스가 유일한 길이다.** 비행기 모드에서는 안드로이드가 핫스팟을 통째로 잠근다. Wi-Fi 는 집에서 준비할 때만 쓴다.
- **통화(음성·영상)는 없다.** 블루투스로는 목소리를 나를 수 없다. 단추는 남기고 누르면 "준비 중" 이라고 알린다. 통화 탭은 뺐다.
- **사진과 음성 메시지는 블루투스로 간다.** 작게 줄여서 천천히. 보내기 전에 얼마나 걸릴지 알리고 사용자가 고른다.
- **여섯 자리 코드는 없앴다.** 두 사람이 쓰는 앱이라 남을 거를 일이 없고, 코드가 안 맞아 대화를 못 하는 편이 훨씬 나쁘다.
- 이름 옆에 상대의 **상태 메시지**가 늘 떠 있다. 이름·캐릭터·상태 메시지를 바꾸면 바로 반영된다.
- 홈 화면 이름을 **SkyTalk** 으로 바꿨다. 패키지·번들·저장소 이름은 `skywalkie` 그대로다.

## 1. 이 앱은 무엇인가

비행기에서 떨어져 앉은 두 사람이 **인터넷 없이** 서로 글과 사진, 음성 메시지를 주고받는 앱이다.

기내 Wi-Fi를 사거나 승무원을 부르지 않고, 두 사람의 휴대폰만으로 둘만의 통신망을 만든다.

### 제품 이름

- 표시 이름: **SkyTalk** (2026-09-19 에 Skywalkie 에서 바꿨다. 메신저에 가까워졌기 때문이다)
- 패키지 식별자: `com.ybbarng.skywalkie` (바꾸면 새 앱이 되어 대화가 사라지므로 그대로 둔다)
- 폴더 이름은 `walkie-talkie`로 두되 홈 화면 이름만 SkyTalk 으로 쓴다.

### 쓰는 사람

정확히 두 명이다. 그룹 채팅도, 친구 추가도, 회원 가입도 없다.

| | 사람 A | 사람 B |
|---|---|---|
| 기기 | 안드로이드 폰 | 아이폰 |
| 이어폰 | 갤럭시 버즈 프로 | 에어팟 프로, 무선 헤드폰 |
| 역할 | 알리는 쪽(호스트) | 찾는 쪽(게스트) |

둘 다 앱을 처음 쓴다. **서로 말을 할 수 없는 상황에서 각자 화면만 보고 연결에 성공해야 한다.** 이게 이 앱의 가장 중요한 요구사항이다.

## 2. 꼭 되어야 하는 것

### F1. 두 기기가 서로 찾아 연결된다

- 두 폰 다 **블루투스만 켜면** 앱이 상대를 자동으로 찾아 이어진다. 누를 것이 없다.
- 못 찾아도 접지 않고 계속 찾는다. 예전의 여섯 자리 코드나 주소 입력은 없앴다(2026-09-19).
- 이어져 있는 동안 눈에 안 보이는 심장박동을 주고받아 **진짜로 이어져 있는지** 확인한다. 한참 조용하면 끊긴 것으로 보고 찾는 쪽이 다시 찾는다.
- 연결 상태는 이름 옆의 점(초록·빨강)으로 늘 보이고, 끊기면 화면 위에 띠가 내려와 무슨 일인지 말한다. 이어져 있으면 띠는 잠시 뒤 사라진다.
- 이름 밑에는 이어져 있으면 상대 배터리, 끊겼으면 "N분 전까지 이어져 있었어요" 가 보인다.

### F2. 메시지를 주고받고 기기에 남는다

- 텍스트 메시지를 주고받는다. 카카오톡을 대신하는 자리다.
- 메시지는 **각자의 기기에 저장**되어 비행기에서 내린 뒤에도 다시 볼 수 있다.
- 연결이 끊긴 동안 보낸 메시지는 대기하다가 다시 붙으면 자동으로 전달된다.
- 보냄 / 전달됨 / 읽음 상태가 보인다. 상대가 입력 중이면 표시된다.
- 같은 사람이 이어 말하면 같은 분(分) 안의 마지막에만 시각이 찍히고, 분이 바뀌면 그 앞 말에도 찍힌다. 날이 바뀌면 사이에 날짜가 들어간다.
- 대화 목록은 아래쪽이 기준점이다. 키보드나 도구 줄이 열려도 보던 아래쪽이 그대로 따라온다.

### F2-1. 대화와 데이터를 꺼내서 보관할 수 있다

앱이 사라져도 대화는 남아야 한다. 아이폰 앱이 7일마다 만료되는 조건에서 이건 부가 기능이 아니라 필수다.

- **통째로 내보내기**: 대화 전체, 설정, 캐릭터 선택을 하나의 파일로 묶어 내보낸다. 기기의 공유 창으로 Google Drive·파일 앱·메일 어디로든 보낼 수 있다.
- **읽을 수 있는 형태로 내보내기**: 날짜별 텍스트 파일과 그대로 열어볼 수 있는 HTML 파일.
- **되돌리기**: 내보낸 파일을 다시 불러오면 대화가 그대로 복원된다.
- **중복 없이 합치기**: 같은 메시지가 두 번 쌓이지 않는다.
- **누락 없음 확인**: 메시지 개수와 검증값을 적어두고 불러올 때 대조한다.
- **안드로이드 릴리즈 빌드에서는 `adb` 로 대화 DB 를 못 꺼낸다.** 앱 전용 폴더라 접근이 안 된다. 그래서 위의 내보내기가 유일한 길이고, 설정 → 대화 꺼내두기 → 공유로 Google Drive 에 올리면 된다.
- **대화 비우기**: 화면에서 지금까지의 말을 치운다. **지우지 않고 감춘다.** 지우면 순번이 0으로 돌아가 다음 인사 때 상대가 전부 다시 보내 화면이 도로 채워지기 때문이다. 상대 화면과 꺼내둔 파일에는 그대로 남는다.

자세한 형식과 절차는 [05-messaging-spec.md](./05-messaging-spec.md)에 적는다.

### F3. 사진과 음성 메시지가 블루투스로 간다

2026-09-19 에 바꿨다. 그전에는 블루투스에서 막고 Wi-Fi 를 기다렸는데, 비행기에서는 Wi-Fi 가 영영 안 열린다.

- **사진**: 보낼 때 작게(800px)·중간(1600px)·원본 중에 고른다. 블루투스면 크기마다 얼마나 걸릴지 적는다. 작게가 30초 안팎, 원본은 몇 분이다. 다 받은 사진은 눌러서 크게 보고 두 손가락으로 벌려 확대한다.
- **음성 메시지**: 마이크를 누르면 녹음 창이 열린다. 큰 단추를 누르면 녹음 시작, 다시 누르면 끝. 길어야 20초. 끝나면 보낼지 버릴지 고른다. 받은 쪽은 세모를 눌러 듣는다.
- **진행률**: 보내는 쪽과 받는 쪽 모두 말풍선에 몇 퍼센트 갔는지 실시간으로 보인다.
- **글이 막히지 않는다**: 사진이 가는 동안에도 글은 몇 조각 뒤에 바로 끼어든다.
- 여러 장을 같이 보내도 섞이지 않는다. 대신 각각의 속도가 나뉜다.

### F4. 처음 쓰는 사람이 설명 없이 쓸 수 있다

- 첫 실행 안내는 세 단계다: 환영 → 캐릭터와 이름 → 연결 안내. 말하기 방식과 집 Wi-Fi 안내는 뺐다(2026-09-19).
- 화면의 버튼 옆에 **물음표**가 있어 누르면 "이게 뭐 하는 건지" 한두 줄로 설명한다.
- 문제가 생기면 "무엇이 잘못됐고 무엇을 누르면 되는지"를 한국어로 알려준다. 오류 코드만 띄우지 않는다.
- 도움말에 이어지는 방식, 사진이 오래 걸리는 까닭, 음성 메시지, 콕 찌르기, 비행 시간, 이름과 상태 메시지, 대화 꺼내기, 다른 블루투스 앱을 끄라는 안내가 있다.

### F5. 밝은 화면과 어두운 화면을 모두 지원한다

- 기기 설정을 따라가되, 앱 안에서 따로 고를 수도 있다.
- 기내는 어둡다. 어두운 화면이 기본에 가깝게 잘 다듬는다.

### F6. 서로의 캐릭터와 이름, 상태 메시지가 보인다

- 첫 실행 때 자기 캐릭터와 이름을 고른다. 인사를 주고받으면 상대 화면에 뜬다.
- 설정에서 **상태 메시지**("영화 보는 중" 같은 한마디)를 적으면 상대 화면의 내 이름 옆 빈자리에 늘 떠 있다.
- 이름·캐릭터·상태 메시지를 바꾸면 곧바로 다시 인사해 상대 화면에 반영된다.
- 캐릭터는 **코드로 그리는 벡터**라서 어떤 화면 크기에서도 선명하고, 밝은/어두운 화면에 맞춰 색이 바뀐다. 상대가 말하면 입이 움직이고, 연결이 끊기면 시무룩해진다.

## 3. 되면 좋은 것

### F7. 이모티콘과 콕 찌르기

- 각자 고른 캐릭터가 자세를 취하는 **캐릭터 이모티콘**. 서랍에서 고르고, 대화 안의 이모티콘은 길게 누르면 옆에 뜻이 뜬다.
- **콕 찌르기**: 상대 폰이 짧게 한 번 떨린다. 설정에서 끌 수 있다. 아이폰은 "시스템 햅틱" 이 꺼져 있어도 울리게 진동 모터를 직접 돌린다.

### F8. 남은 비행 시간

- 설정에서 **출발 시각과 도착 시각**을 넣으면 대화 화면 위에 비행기가 왼쪽에서 오른쪽으로 간다. 남은 시간만 넣는 옛 방식도 접이식으로 남겨뒀다.
- 한쪽이 넣으면 상대 화면에도 같이 뜬다. 시각이 아니라 남은 길이와 전체 길이를 보내므로 두 폰의 시계가 달라도 맞는다.
- 남은 시간 글을 누르면 "출발한 지 N시간 M분 됐어요" 로 바뀌고, 다시 누르면 돌아온다.

### F9. 낙서

- 손가락으로 그린 그림을 보낸다. 블루투스로는 크기가 커서 막고 Wi-Fi 를 기다린다.

### F10. 통화 — 준비 중

- 음성·영상 통화 코드(WebRTC)는 남아 있지만 **비행기에서는 쓸 수 없다.** 블루투스로는 목소리를 나를 수 없다.
- 통화 단추는 대화 화면 위에 하나만 남기고, 누르면 "통화는 아직 준비 중이에요" 와 왜 안 되는지를 잠깐 띄운다. 영상 통화 단추와 통화 탭은 뺐다(2026-09-19).
- 집에서 Wi-Fi 로 이었을 때의 설계는 [06-voice-video-spec.md](./06-voice-video-spec.md)에 남겨둔다.

### F11. 비상용 웹 채팅

- 아이폰 앱이 7일 뒤 열리지 않을 때를 위해 안드로이드 앱이 작은 웹 서버를 띄운다. 핫스팟이 있어야 하므로 집에서만 쓸 수 있다.

## 4. 만들지 않는 것

경계를 분명히 해둔다.

- 셋 이상이 참여하는 대화
- 인터넷을 거치는 통신, 계정, 서버
- 메시지가 다른 기기로 동기화되는 기능
- 사진 외의 파일 전송 (문서, 음악 파일 등)
- 동영상 전송
- 여섯 자리 코드로 상대를 거르는 기능 (2026-09-19 에 없앴다)
- 아이폰끼리의 연결 (한쪽은 알리는 쪽이어야 한다. 안드로이드끼리는 이제 된다)

## 5. 반드시 지켜야 하는 제약

### C1. 인터넷이 없다

외부 서버에 의존하는 설계는 전부 쓸 수 없다. 로그인, 푸시 알림, STUN/TURN 서버, 원격 설정, 오류 수집 서비스 모두 안 된다.

### C2. 아이폰 앱은 7일마다 다시 설치해야 한다

유료 개발자 계정이 없어 무료 계정으로 서명한다. 7일이 지나면 앱이 열리지 않는다.

- 여행 **출발 하루 전**에 다시 설치해야 한다.
- 앱을 지우지 않고 **덮어쓰기**로 다시 설치하면 저장된 메시지가 남는다.
- 덮어쓰기가 안 되는 상황에 대비해 F2-1의 내보내기·되돌리기가 항상 동작해야 한다.
- 만료 3일 전부터 앱이 먼저 알린다.
- 덮어쓰면 iOS 가 옛 시작 화면을 캐시해 잠깐 옛 그림이 뜰 수 있다. 재부팅하면 사라진다.

### C3. 비행기 모드에서는 블루투스뿐이다

안드로이드는 비행기 모드에서 핫스팟 메뉴를 잠근다(2026-09-18 실기기 확인). 그래서 블루투스가 보조가 아니라 **유일한 길**이다. 모든 기능은 초당 몇 KB 위에서 돌아가야 한다.

### C4. 다른 블루투스 대화 앱과 같이 쓸 수 없다

bitchat 같은 앱이 두 폰에서 돌면 같은 블루투스 링크를 써서 우리 연결이 끊긴다(2026-09-19 확인). 비행 중에는 완전히 종료한다. 도움말과 연결 상세에 적어뒀다.

### C5. 배터리

비행 시간 내내 켜둘 수 있어야 한다. 화면을 끈 채 대기할 때 전력을 아끼는 설계를 기본으로 한다.

### C6. 개인정보

모든 데이터는 두 기기 밖으로 나가지 않는다. 사용 기록을 수집하는 코드를 넣지 않는다.

## 6. 잘 만들었는지 판단하는 기준

| 기준 | 목표 |
|---|---|
| 처음 켜서 연결까지 | 블루투스만 켜고 1분 안에 |
| 글 전달 지연 | 1초 이내 |
| 사진(작게) 전달 | 30초 안팎, 퍼센트가 실시간으로 움직인다 |
| 음성 메시지(10초) 전달 | 15초 안팎 |
| 연결이 끊겼다 붙기까지 | 40초 이내 자동 복구 (심장박동 35초 + 다시 찾기) |
| 대기 상태 배터리 | 시간당 5% 이내 |
| 놓치는 메시지 | 0건 (끊긴 동안 보낸 것도 전부 도착) |
| 내보내고 되돌리기 | 만 건을 내보내고 다시 불러도 하나도 빠지거나 겹치지 않는다 |

```
첫 실행 (세 단계)

주 화면 (아래 탭 2개)
  ├ 대화       메시지, 이모티콘, 콕 찌르기, 사진, 음성 메시지, 낙서, 비행기 띠
  └ 설정       연결 상태, 이름·상태 메시지·별명, 화면 밝기, 알림·진동,
              비행 시간, 음성 자동 재생, 대화 꺼내기·되돌리기·비우기, 도움말
```

연결 상태는 이름 옆의 점으로 늘 보이고, 끊겼을 때만 화면 위에 띠가 내려온다.

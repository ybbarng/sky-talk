# T10 — 캐릭터 그리기

**단계** 화면 · **상태** 완료 · 실기기 확인 2026-09-19 · **먼저** T02

## 목표

각자의 캐릭터가 화면에 살아 움직인다. 상대가 말하면 입이 움직이고, 연결이 끊기면 시무룩해진다.

## 근거

## 할 일

```
src/presentation/characters/
  Character.tsx        표정과 캐릭터를 받아 그리는 부품
  parts/
    Face.tsx           얼굴 바탕, 눈, 입, 볼
    Hair.tsx           머리 모양 6가지
    Accessory.tsx      헤드폰, 안경, 이어폰, 후드, 목도리, 모자
  expressions.ts       표정별 눈·입 모양 값
  palettes.ts          캐릭터별 색 (밝은/어두운 화면 각각)
```

### 왜 코드로 그리는가

캐릭터는 가만히 있지 않는다. 그림 파일로는 입을 움직일 수 없다. SVG를 코드로 그리면 표정을 값으로 바꿀 수 있고, 어떤 화면 크기에서도 선명하고, 앱 크기가 거의 늘지 않는다.

### 얼개 하나에 머리와 소품만 다르게

여섯 캐릭터가 같은 얼굴 얼개를 쓴다. 그래야 표정 코드를 한 벌만 만들면 된다.

| 이름 | 머리 | 소품 |
|---|---|---|
| `aria` | 긴 머리 | 헤드폰 |
| `nova` | 단발 | 안경 |
| `orion` | 짧은 머리 | 이어폰 |
| `atlas` | 곱슬 | 후드 |
| `luna` | 묶은 머리 | 목도리 |
| `pilot` | 짧은 머리 | 조종사 모자 (숨겨둔 것) |

### 표정

```
idle          가끔 눈을 깜빡인다. 천천히 위아래로 숨 쉰다
speaking      입이 소리 크기에 맞춰 움직인다
listening     살짝 고개를 기울인다
typing        머리 위에 점 세 개가 차례로 뛴다
disconnected  회색이 되고 눈이 반쯤 감긴다
sleeping      눈을 감고 Z가 뜬다
videoOff      영상을 끈 자리에 나타난다
```

### 입 움직임

```tsx
<Character id="aria" expression="speaking" level={0.7} />
```

`level`은 0에서 1 사이의 소리 크기다. 60분의 1초마다 새 값을 받아 입 벌린 정도를 바꾼다. **진짜로 말하는 것처럼 보이는 지점이 여기다.**

값이 뚝뚝 끊기지 않게 부드럽게 따라가게 한다. 실제 소리는 들쭉날쭉해서 그대로 쓰면 입이 떨린다.

### 움직임 줄이기

기기에서 동작 줄이기를 켠 사람에게는 깜빡임과 숨쉬기를 없앤다. 입 움직임은 정보라서 남긴다.

## 테스트

- 여섯 캐릭터 × 일곱 표정 = 42가지가 전부 오류 없이 그려진다
- 밝은/어두운 화면에서 색이 바뀐다
- `level`이 0과 1 밖으로 나가도 깨지지 않는다
- 동작 줄이기에서 반복 움직임이 없다

## 하면서 알게 된 것

### 그리는 일과 정하는 일을 갈랐다

SVG 를 그리는 코드는 시험하기 어렵다. 그런데 **"어떤 표정일 때 눈과 입이
얼마나 열리는가"는 순수한 계산**이다. 그래서 `expressions.ts` 로 빼서
전부 시험했다.

이 덕에 "두 표정이 똑같으면 상태가 바뀌어도 화면이 안 변한다" 같은 것도
테스트로 잡을 수 있다.

### 입이 떨리는 문제

실제 소리 크기는 한 프레임마다 크게 오르내린다. 그대로 입에 반영하면
떨리는 것처럼 보인다.

**열릴 때는 빠르게, 닫힐 때는 천천히** 따라가게 했다. 말과 입이 맞으려면
벌리는 건 빨라야 하고, 다무는 건 천천히여야 자연스럽다. 이 비대칭을
테스트로 고정했다.

### 눈을 거의 감았을 때

납작한 타원은 어색해 보인다. 0.12 아래로 감기면 **선 하나로** 바꿔 그린다.

### 회색을 섞지 않았다

끊겼을 때 색을 섞어 회색으로 만들면 캐릭터마다 다른 회색이 나와 어떤 건
잘 안 보인다. 미리 만든 회색 팔레트로 통째로 갈아 끼운다.

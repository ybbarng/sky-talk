## 목표

두 폰의 홈 화면에 이 앱이 제대로 보인다.

## 근거

## 할 일

### 그림

종이비행기와 소리의 파동을 합친 모양이다. 밤하늘 색 바탕 위에 따뜻한 주황으로 그린다. 디자인 토큰의 `me` 색과 `bg` 색을 그대로 쓴다.

```
assets/icon/
  icon.svg              원본
  icon-foreground.svg   안드로이드용 앞면 (비행기만)
  icon-background.svg   안드로이드용 뒷면 (밤하늘 그러데이션)
  splash.svg            앱을 열 때 잠깐 뜨는 화면
```

**원본은 SVG로 그리고 필요한 크기로 뽑아낸다.** 손으로 그린 그림 파일을 저장소에 두지 않는다. 색을 바꾸면 전부 다시 만들어야 하기 때문이다.

### 뽑아내는 명령

```bash
pnpm icons:generate
```

SVG를 읽어 필요한 크기의 PNG를 전부 만든다. 만들어진 PNG는 저장소에 넣지 않는다(`.gitignore`). `prebuild` 전에 자동으로 돈다.

### 안드로이드

앞뒤가 나뉜 형태로 만든다. 폰마다 아이콘 모양(동그라미, 네모, 물방울)이 달라서 시스템이 알아서 자른다. **중요한 것이 잘리지 않도록 가운데 66%인 안전 영역 안에 비행기를 둔다.**

단색 아이콘도 만든다. 안드로이드 13부터 테마에 맞춰 색을 바꾸는 기능이 있다.

### 아이폰

한 장(1024×1024)만 만든다. 모서리는 시스템이 자른다. **투명한 부분이 있으면 안 된다.**

### 여는 화면

앱을 열 때 잠깐 뜨는 화면도 같은 그림으로 만든다. 바탕색이 앱 첫 화면과 같아야 깜빡임이 없다. 밝은 화면과 어두운 화면 각각 만든다.

## 하면서 알게 된 것

### 그림을 세 번 갈았다 — 2026-09-19

1. **종이비행기** → "정말 하늘을 나는 비행기" 로 해달라고 했다.
2. **봉투 위에 실링처럼 여객기** → 실링 원 때문에 비행기가 안 보였다. 원을 빼고 키워도
   작게 줄이면 봉투인지 비행기인지 안 읽혔다.
3. **밤하늘 위 주황 여객기 옆모습, 켜진 창문 둘 사이로 봉투가 날아간다** ← 지금 것.
   시안 열두 개(창문 사이 메시지 여섯, 동체에 TALK 여섯)를 한 페이지에 띄워 골랐다.
   고른 시안에서 초승달은 뺐다.

홈 화면 이름도 같은 날 **SkyTalk** 로 바꿨다(`plugins/withDisplayName.js`). 글만 주고받는
메신저가 됐는데 "워키토키" 는 이제 안 맞는다. 번들·패키지 이름은 그대로다.

### 아이콘을 바꿔도 홈 화면이 안 바뀌던 이유

`pnpm icons:generate` 는 PNG 만 만든다. 네이티브 프로젝트에 넣는 것은 `expo prebuild` 고,
그 뒤 다시 빌드해야 한다. 아이폰은 여기에 더해 스플래시를 저장해 둬서 **껐다 켜야** 새
그림이 뜬다. 순서는 [08-build-release.md](../08-build-release.md) 2.2 에 적었다.

### 비행기를 기울이면 커서처럼 보인다

처음에 종이비행기를 20도 기울여 그렸더니 **마우스 커서처럼 보였다.**
날아가는 느낌을 주려던 건데 오히려 무엇인지 알아보기 어려워졌다.

기울이지 않고 위를 향하게 하고, 왼쪽 날개를 밝게 오른쪽 날개를 어둡게
칠해 접힌 종이라는 게 드러나게 했다.

### 검사 도구가 아이콘 SVG 를 화면 코드로 봤다

biome 가 `.svg` 를 JSX 처럼 읽어 "접근성 제목이 없다"고 했다. 이 SVG 는
화면에 들어가는 게 아니라 PNG 로 바꾸는 원본이라 검사 대상에서 뺐다.
화면에 쓰는 SVG(아이콘 컴포넌트, 캐릭터)는 `.tsx` 라 계속 검사받는다.

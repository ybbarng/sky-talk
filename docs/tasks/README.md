# 작업 카드

> 최종 수정 2026-09-19 — 출발 전 두 폰에 올린 최종 빌드 기준

명세를 실제로 만들 수 있는 크기로 쪼갠 목록이다. **하나씩 끝내고 커밋한다.**

## 읽는 법

각 카드에는 이것이 들어 있다.

- **목표** — 이 카드가 끝나면 무엇이 되는가
- **근거** — 어느 명세 문서의 어느 부분인가
- **할 일** — 만들 파일과 내용
- **끝난 걸 어떻게 아는가** — 이게 전부 되면 카드를 닫는다
- **먼저 끝나야 하는 카드**

## 어디까지 하면 "쓸 수 있는 앱"인가

중간에 멈춰도 쓸 수 있는 지점을 표시해둔다.

| 지점 | 무엇이 되나 |
|---|---|
| **T14까지** | **글로 대화할 수 있다.** 이것만으로도 목적의 절반은 달성된다 |
| **T20까지** | **비행기 모드에서 된다.** 핫스팟이 안 켜지므로 블루투스가 있어야 비행기에서 쓸 수 있다 |
| T19까지 | 대화를 보관하고 되돌린다. 아이폰 7일 문제가 해결된다 |
| T24까지 | 사진과 이모티콘, 콕 찌르기, 비행기 막대까지 |
| ~~T17까지~~ | ~~음악 들으며 목소리로 대화한다~~ 보류. 첫 비행은 글·사진·음성 메시지로 간다 |

**T14와 T19를 먼저 끝내는 것을 권한다.** 글로 대화가 되고 대화가 안 날아가면, 그 뒤는 전부 덤이다.

2026-09-19 기준 두 폰에 올라간 것은 T24 까지 전부다(통화 넷 빼고). 아래 "카드 밖에서 한 것" 도 들어 있다.

## 나중에 해볼 것

- **더 보낼 것들** — 위치(좌석 번호), 짧은 영상, 노래 한 소절 공유
  같은 것. 낙서·사진·음성이 이미 `assetId` 로 바이트만 나르는 길을
  쓰므로, 새 종류는 `MessageContent` 에 한 줄 더하고 말풍선만 그리면
  된다. (`ChunkSender` 는 무엇인지 묻지 않는다)
- **아이폰 안 재우기** — `audio` 배경 모드로 무음을 흘리면 뒤로 가도
  연결이 안 끊긴다. 배터리를 먹어서 설정으로 두기로 했다.

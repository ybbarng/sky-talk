# T21 — 비상용 웹 채팅

**단계** 보조 · **상태** 대기 · **먼저** T09

## 목표

**아이폰 앱이 만료돼도 대화할 수 있다.** 설치 없이 사파리로 들어온다.

## 근거

[04-transport-spec.md](../04-transport-spec.md) 5장 · [01-product-spec.md](../01-product-spec.md) F8

## 할 일

```
src/infrastructure/transport/web/
  LocalHttpServer.ts        안드로이드가 띄우는 작은 서버
  LocalHttpTransport.ts
  client/
    index.html              한 장짜리 화면
    build.ts                HTML을 문자열로 묶어 앱에 넣기
```

### 구조

```
  안드로이드 앱                        아이폰 사파리
 ┌──────────────┐                  ┌──────────────┐
 │ 작은 웹 서버  │◀── HTTP ────────│ 192.168.x.1  │
 │ 51705번      │                  │   :51705     │
 │              │──── SSE ────────▶│              │
 └──────────────┘                  └──────────────┘
```

- 안드로이드 앱이 HTML 한 장과 실시간 통로(SSE)를 내어준다
- 웹에서 주고받은 메시지도 **안드로이드 쪽 데이터베이스에 똑같이 저장된다.** 나중에 내보내기에 포함된다

### 한 장으로 만든다

HTML, CSS, JavaScript를 한 파일에 담는다. 바깥에서 아무것도 불러오지 않는다. 인터넷이 없기 때문이다.

빌드할 때 이 파일을 문자열로 바꿔 앱 안에 넣는다.

### 글자만 된다

브라우저는 인터넷 없는 환경(HTTPS가 아닌 곳)에서 마이크와 카메라를 열어주지 않는다. 이 제약은 우회할 수 없다. 화면에 왜 통화가 안 되는지 적어둔다.

### 들어올 때 확인

사설망에 다른 사람이 붙을 수 있지만 따로 코드를 묻지 않는다. 앱의 여섯 자리 코드 기능을 없앴고(2026-09-19), 핫스팟 비밀번호가 곧 문이다.

### 웹 화면

앱과 같은 색과 모양으로 만든다. 밝은/어두운 화면도 지원한다. 캐릭터는 간단한 형태로 다시 그린다(앱의 SVG를 그대로 쓸 수 없다).

### 켜고 끄기

기본은 꺼져 있다. 설정에서 켠다. 켜면 화면에 접속 주소와 코드가 크게 뜬다.

## 테스트

- 서버가 뜨고 HTML을 내어준다
- 코드가 틀리면 들어오지 못한다
- 웹에서 보낸 메시지가 앱 데이터베이스에 저장된다
- 앱에서 보낸 메시지가 웹에 실시간으로 나타난다
- 브라우저를 껐다 켜면 옛 대화가 보인다
- 서버를 끄면 자원이 정리된다

## 끝난 걸 어떻게 아는가

- [ ] 아이폰 사파리에서 설치 없이 대화가 된다
- [ ] 코드 없이는 못 들어온다
- [ ] 웹 대화가 내보내기에 포함된다

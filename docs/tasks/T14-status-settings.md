# T14 — 화면: 연결 상태와 설정

**단계** 화면 · **상태** 코드 완료 · 기기 확인 대기 · **먼저** T13

지금 연결이 어떤 상태인지 늘 보이고, 문제가 생기면 무엇을 해야 할지 알 수 있다.

### 맨 위 띠

어느 탭에 있든 보인다.

| 상태 | 색 | 글 |
|---|---|---|
| 연결됨 (Wi-Fi) | `success` | 연결됨 |
| 연결됨 (블루투스) | `warning` | 블루투스로 연결됨 · 글자만 가능 |
| 찾는 중 | `textMuted` | 상대를 찾는 중... |
| 끊김 | `danger` | 연결이 끊겼어요 · 다시 붙는 중 |

색이 바뀔 때 0.4초에 걸쳐 서서히 변한다. 깜빡이지 않는다.

### 자세히 보기

띠를 누르면 아래에서 올라온다.

```
연결 방식      Wi-Fi
상대           여자친구 (192.168.43.5)
신호           좋음
응답 시간      23밀리초
주고받은 양    ↑ 1.2 MB  ↓ 3.4 MB
보낼 것        0건
연결된 지      1시간 23분

[다시 연결하기]
```

문제가 생겼을 때 여기서 무엇이 잘못됐는지 알 수 있어야 한다.

### 설정

```
연결
  연결 상태
  첫 실행 안내 다시 보기

화면
  밝기 모드         기기 설정 따라가기 / 밝게 / 어둡게
  내 캐릭터
  상대 캐릭터

소리
  말하기 방식       세 가지 중 하나 (그림 설명과 함께)
  상대가 말하면 음악 줄이기
  볼륨 버튼으로 말하기

대화
  대화 내보내기       → T19
  대화 불러오기       → T19
  자동 보관           → T19

이 앱에 대하여
  버전
  앱이 열리는 기간    (아이폰만)
  도움말
```

### 도움말

물음표에 흩어져 있는 설명을 한 화면에 모은다. 반년 뒤 다시 쓸 때 여기만 보면 된다.

```
연결이 안 돼요
  · 두 폰이 같은 Wi-Fi에 있나요?
  · 안드로이드에서 핫스팟이 켜져 있나요?
  · 비행기 모드에서 Wi-Fi가 켜져 있나요?
  · 잠시 기다리면 앱이 다시 찾아요

음악이 꺼져요 / 음질이 나빠요
  · 말하기 방식을 바꿔보세요 [설정 열기]
  · 왜 그런지: (이어폰의 동작 방식 설명)

목소리가 안 들려요
  · 마이크 권한 [설정 열기]
  · 이어폰이 제대로 연결됐나요?

아이폰에서 앱이 안 열려요
  · 7일이 지나면 다시 설치해야 해요
  · (다시 설치하는 방법)
```

### 코드로 연결하기 — 없앴다

여섯 자리 코드 기능을 2026-09-19 에 걷어냈다. 두 사람이 쓰는 앱이고, 비행기 안에서
코드를 맞추다 대화를 못 하는 편이 남이 붙는 것보다 훨씬 나쁘다. 자동 찾기가 실패하면
앱이 잠시 뒤 스스로 다시 찾는다.

## 테스트

- 연결 상태가 바뀌면 띠가 따라 바뀐다
- 밝기 모드를 바꾸면 즉시 적용되고 앱을 껐다 켜도 유지된다
- 말하기 방식을 바꾸면 통화 중에도 적용된다
- 코드를 입력하면 그 주소로 연결을 시도한다

## 끝난 걸 어떻게 아는가

- [x] 어느 화면에서든 연결 상태가 보인다 (탭 위 띠)
- [x] 밝기 모드를 바꾸면 즉시 적용되고 앱을 껐다 켜도 유지된다
- [x] 말하기 방식을 설정에서 바꿀 수 있다
- [x] 도움말에 흔한 문제 여섯 가지와 해결 방법이 있다
- [x] ~~코드로 연결하기 화면이 있다~~ 기능을 없앴다
- [ ] **두 폰으로 글 대화 끝까지 해보기** — **기기 필요**

## 하면서 알게 된 것

### 통화 탭을 빈 화면으로 두지 않았다

T15~T17 전이라 통화는 아직 안 된다. 그런데 **빈 화면을 두면 사용자는
앱이 고장난 줄 안다.** 자는 캐릭터와 함께 "여기에 무엇이 들어올지"를
적어두었다.

설정의 내보내기도 같은 이유로 "T19 에서 열립니다"라고 흐리게 표시했다.
아예 숨기면 나중에 생겼을 때 못 찾는다.

### 도움말에 "왜"를 적었다

"음악이 꺼져요" 항목에 **이어폰이 마이크를 켜는 순간 음질이 떨어지는
이유**를 적었다. 방법만 알려주면 앱이 이상한 줄 안다. 어쩔 수 없는
일이라는 걸 알면 납득하고 다른 방식을 고른다.

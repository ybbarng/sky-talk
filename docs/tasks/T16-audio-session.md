# T16 — 통화: 소리 설정과 음악 함께 듣기

**단계** 통화 · **상태** 코드 완료 · 보류 (여는 단추 없음) · **먼저** T15

## 목표

**음악을 들으면서 대화한다.** 요구사항 중 가장 까다로운 부분이고, 이 카드가 그것만 다룬다.

## 근거

[06-voice-video-spec.md](../06-voice-video-spec.md) 2장, 4장 · [01-product-spec.md](../01-product-spec.md) F3

## 먼저 알아야 할 것

무선 이어폰은 **듣기만 할 때**와 **말도 할 때** 서로 다르게 동작한다. 마이크를 켜는 순간 음질이 떨어진다. 이건 이어폰과 운영체제가 정하는 일이라 앱이 거스를 수 없다.

즉 "좋은 음질로 음악을 들으면서 이어폰 마이크로 말하기"는 **불가능하다.** 그래서 세 가지 방식을 만들고 사용자가 고르게 한다.

## 할 일

```
src/application/ports/
  AudioSessionController.ts
src/infrastructure/audio/
  AudioSessionController.ios.ts
  AudioSessionController.android.ts
  AudioRouteWatcher.ts        이어폰이 빠지고 꽂히는 것 감시
src/domain/call/
  AudioMode.ts                세 방식
  AudioRoute.ts
```

### 세 가지 방식

| | 마이크 | 음악 음질 | 언제 |
|---|---|---|---|
| **1. 말할 때만 잠깐** (기본값) | 이어폰, 누를 때만 | 말할 때만 잠깐 나빠짐 | 대부분의 경우 |
| **2. 폰 마이크로** | 폰 내장, 계속 | 계속 좋음 | 손이 자유로워야 할 때 |
| **3. 전화처럼** | 이어폰, 계속 | 계속 나쁨 | 음악 없이 대화만 |

### 아이폰

```
category:  playAndRecord
mode:      voiceChat
options:
  · mixWithOthers        다른 앱 소리를 끄지 않는다   ← 음악이 살아남는 이유
  · duckOthers           내 소리가 날 때 줄인다
  · allowBluetoothA2DP   이어폰 좋은 음질 출력
  · allowBluetoothHFP    (방식 1·3만) 이어폰 마이크
```

**방식 2에서 `allowBluetoothHFP`를 빼는 것이 핵심이다.** 이러면 iOS가 이어폰 마이크를 후보에서 빼고 폰 마이크를 쓴다. 이어폰은 출력 전용으로 남아 음질이 유지된다.

방식 1에서는 버튼을 누를 때 설정을 바꾸고 뗄 때 되돌린다. 바꾸는 데 0.1초쯤 걸리므로 **준비되면 짧은 소리를 내어 알린다.** 그 전에 말하면 앞부분이 잘린다.

### 안드로이드

```
usage:        USAGE_VOICE_COMMUNICATION
contentType:  CONTENT_TYPE_SPEECH
audioFocus:   AUDIOFOCUS_GAIN_TRANSIENT_MAY_DUCK
              (내 소리 날 동안 네 소리를 줄여라. 끄지는 말고)
```

방식 2는 안드로이드 12부터 있는 통신 기기 지정 기능으로 폰 마이크를 고정한다.

### 음악 줄이기

- 목소리가 시작되면 **0.2초에 걸쳐 25%까지** 줄인다
- 목소리가 멎고 **0.8초 뒤** 되돌린다. 문장 사이 침묵마다 오르내리는 걸 막는다
- 앱이 음악 앱을 조종하는 게 아니라 운영체제에 요청하는 방식이다

### 이어폰을 뺐다 꼈다 할 때

- 빠지면 **마이크를 즉시 끈다.** 대화가 스피커로 새는 걸 막는다. 왜 껐는지 화면에 알린다
- 다시 껴도 자동으로 켜지 않는다. 사용자가 켤 때까지 기다린다
- 이어폰이 바뀌면(에어팟 → 헤드폰) 설정을 다시 잡는다

### 화면을 꺼도 이어지게

**아이폰**: `UIBackgroundModes`에 `audio`. 소리가 완전히 멎으면 iOS가 앱을 재우므로 **아주 작은 소리를 계속 흘려** 잠들지 않게 한다.

**안드로이드**: 앞에서 도는 서비스를 띄운다. 종류는 `microphone` + `mediaPlayback`. 알림에서 바로 끊을 수 있게 한다.

## 테스트

**컴퓨터에서**
- 방식을 바꾸면 설정이 올바르게 바뀐다 (`FakeAudioController`로 기록한 값 확인)
- 방식 2에서 이어폰 마이크를 허용하지 않는다
- 이어폰이 빠지면 마이크가 꺼진다
- 줄이고 되돌리는 시간이 정확하다 (`FakeClock`으로)
- 통화가 끝나면 설정이 원래대로 돌아간다

**실제 기기로** — 이게 진짜 시험이다
- 음악을 틀고 통화할 때 음악이 안 꺼진다
- 상대가 말하면 음악이 작아지고 끝나면 돌아온다
- 방식 2에서 이어폰 음질이 안 떨어진다
- 에어팟 프로, 버즈 프로, 무선 헤드폰 각각에서 된다
- 화면을 끄고도 대화가 이어진다
- 이어폰을 뺐다 끼면 소리가 안 엉킨다

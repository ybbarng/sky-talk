# T12 — 화면: 첫 실행 안내

**단계** 화면 · **상태** 완료 · 실기기 확인 2026-09-19 · **먼저** T02, T09, T10

## 목표

**말을 나눌 수 없는 두 사람이 각자 화면만 보고 연결에 성공한다.** 이 앱에서 가장 중요한 화면이다.

## 근거

[01-product-spec.md](../01-product-spec.md) F4 · [07-design-system.md](../07-design-system.md) 8장

## 할 일

```
app/onboarding/
  welcome.tsx        환영
  role.tsx           역할 고르기
  character.tsx      캐릭터 고르기
  connect.tsx        연결 안내 (역할별로 다름)
  permissions.tsx    권한 요청
```

### 역할 고르기

"내 폰은 어느 쪽인가요?"를 묻는다. 기기 종류로 미리 골라두되 바꿀 수 있게 한다.

- 안드로이드 → **무선망을 여는 쪽**
- 아이폰 → **접속하는 쪽**

고른 역할에 따라 다음 화면이 완전히 달라진다. **상대가 할 일까지 같이 보여주면 헷갈린다.**

### 연결 안내 — 이 앱의 핵심 화면

```
안드로이드 쪽                      아이폰 쪽
1. 비행기 모드를 켜요              1. 비행기 모드를 켜요
2. Wi-Fi를 켜요                   2. Wi-Fi를 켜요
3. 핫스팟을 켜요  [설정 열기]      3. 목록에서 상대 폰을 골라요
4. 이 화면을 상대에게 보여줘요     4. 연결되면 자동으로 찾아요
```

**3단계에서 안드로이드 화면에 핫스팟 이름과 비밀번호가 크게 뜬다.** 말을 못 해도 화면을 보여주면 된다. 글자를 가장 크게(`display`) 하고 한 손으로 들어 보여줄 수 있게 배치한다.

앱이 핫스팟을 대신 켜줄 수는 없다([02-tech-decisions.md](../02-tech-decisions.md) D10). 설정 화면으로 데려다주고, 돌아오면 켜졌는지 확인해 다음 단계로 넘긴다.

각 단계에 그림을 둔다. **글을 안 읽어도 무엇을 누를지 보여야 한다.**

### 기다리는 동안 보여주기

```
상대를 찾고 있어요
  ✓ Wi-Fi에 연결됨 (192.168.43.5)
  ⟳ 같은 Wi-Fi에서 상대 찾는 중...
  · 연결

  15초가 지나면: 잘 안 되나요? (안내가 뜬다)
```

빙글빙글 도는 표시만 두면 사용자는 앱이 멈춘 줄 안다. T08에서 내보내는 진행 상황을 그대로 보여준다.

### 권한

필요할 때 필요한 것만 묻는다. 처음에 한꺼번에 묻지 않는다.

| 권한 | 언제 | 뭐라고 설명하나 |
|---|---|---|
| 주변 기기 (안드로이드) | 연결 안내에서 | 상대 폰을 찾기 위해 필요해요 |
| 마이크 | 통화를 처음 열 때 | 목소리를 전하려면 필요해요 |
| 카메라 | 영상 통화를 처음 열 때 | 얼굴을 보여주려면 필요해요 |
| 알림 | 대화 화면에 처음 들어갈 때 | 메시지가 오면 알려드릴게요 |

거절해도 나머지 기능은 동작해야 한다. 거절한 뒤에 필요해지면 설정으로 가는 길을 안내한다.

### 말하기 방식 고르기 — 없앴다

2026-09-19 에 이 단계를 뺐다. 통화가 없어 말하기 방식이 의미가 없다. 설정의 소리 절도 같이 뺐다.

#### 예전 내용

[06-voice-video-spec.md](../06-voice-video-spec.md) 2.2의 세 방식을 **그림으로** 설명한다. 글로만 쓰면 아무도 안 읽는다.

기본값은 1번(말할 때만 잠깐)이다. 나중에 설정에서 바꿀 수 있다고 알린다.

### 다시 보기

첫 실행 안내를 설정에서 언제든 다시 볼 수 있게 한다. 반년 뒤 다시 쓸 때 절차를 기억하지 못한다.

## 테스트

- 역할을 고르면 그에 맞는 단계만 나온다
- 핫스팟이 켜지면 자동으로 다음 단계로 넘어간다
- 권한을 거절해도 앱이 진행된다
- 15초 뒤 "잘 안 되나요" 안내가 나타난다
- 안내를 다 보면 주 화면으로 가고, 다시 켰을 때 안내가 안 나온다

## 끝난 걸 어떻게 아는가

- [x] ~~역할을 고르면 그에 맞는 단계만 나온다~~ 역할을 안 고른다. 안드로이드가 알리고 아이폰이 찾는다
- [x] ~~여섯 자리 코드를 화면에서 가장 크게 띄운다~~ 코드 기능을 없앴다
- [x] 설정 화면으로 데려다주는 버튼이 있다 (블루투스 설정)
- [x] 안내를 마치면 다시 안 나온다 (기기에 저장)
- [x] **처음 보는 사람이 3분 안에 연결한다** — 2026-09-19 두 폰 다 안내를 처음부터 다시 보고 이었다
- [ ] 각 단계에 그림 넣기 — 지금은 글과 번호만 있다

## 하면서 알게 된 것

### 세 단계로 줄였다 — 2026-09-19

원래 다섯이던 것을 셋(시작하기 → 나를 어떻게 보여줄까요 → 이어보기)으로 줄였다.

- **"말하기 방식 고르기"** 를 뺐다. 통화가 보류라 고를 것이 없다. 설정의 "소리" 절도 같이 뺐다.
- **"집에서는 Wi-Fi 로 더 많이"** 카드를 뺐다. 비행기 모드에서는 핫스팟이 안 켜져서 자리에
  앉은 사람에게 잠긴 메뉴만 보게 했다. 집에서 쓰는 길은 도움말에만 남겼다.
- 이어보기는 **블루투스만 켜면 된다**는 것과 알림 권한만 말한다.

### 층 검사가 화면 코드를 잡았다

화면 스토어가 저장소 구현(`infrastructure/platform/Settings`)을 직접
가져왔더니 `pnpm check:deps` 가 막았다. 규칙대로다.

그런데 **화면도 결국 저장소가 필요하다.** 어디선가는 받아야 한다.
`composition/services.ts` 를 두고 거기서 받도록 했다.

```
presentation ──▶ composition ──▶ infrastructure
```

이러면 "지금 무엇이 끼워져 있는지"를 아는 곳이 한 군데로 남는다.
대신 `composition` 에는 조립만 있고 판단이 없어야 한다는 규칙을
[03-architecture.md](../03-architecture.md) 에 적었다.

### 코드를 화면에서 가장 크게 만들었다

말을 못 하는 상황에서 상대에게 보여주는 것이라, 한 손으로 들어 보여줄
크기여야 한다. `display` 크기에 자간을 넓히고 세 자리씩 끊었다.

### 아직 그림이 없다

각 단계에 "무엇을 누를지" 보여주는 그림을 넣기로 했는데 번호와 글만
있다. 글을 안 읽어도 알 수 있게 하려면 그림이 필요하다. 남은 일이다.

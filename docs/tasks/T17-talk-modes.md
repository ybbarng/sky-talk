### 누르고 말하기 버튼

화면 아래쪽에 크고 둥글게 둔다. 흔들리는 기내에서 좁은 좌석에 앉아 한 손으로 누른다.

```
누름    → 소리 설정을 바꾼다 (0.1초)
        → 준비되면 짧은 소리 + 진동
        → 이제 말한다
        → 버튼이 천천히 맥박친다

뗌      → 0.3초 뒤에 닫는다 (말끝이 잘리지 않게)
```

**위로 밀면 잠긴다.** 계속 누르고 있지 않아도 되고 다시 누르면 풀린다. 긴 이야기를 할 때 손가락이 아프지 않다. 잠긴 상태는 화면에 분명히 표시한다.

### 볼륨 버튼으로 말하기

화면이 꺼져 있어도 볼륨 버튼으로 누르고 말하기가 되게 한다. **주머니에 넣은 채로도 쓸 수 있다.** 설정에서 끌 수 있다.

### 항상 열기

- 마이크가 계속 열려 있다
- 소리가 없을 땐 전송을 멈춘다. 배터리와 대역폭을 아낀다
- **마이크를 끄는 버튼이 늘 보인다.** 껐는지 켰는지 화면에서 바로 알아야 한다. 이게 헷갈리면 사고가 난다

### 방식 바꾸기

통화 중에 언제든 바꿀 수 있다. 바꾸면 **상대에게도 알린다.** 상대 화면에 "지금 누르고 말하는 중"이 표시된다. 상대가 왜 조용한지 몰라 답답한 상황을 막는다.

### 통화 화면

```
┌─────────────────────────┐
│    연결됨 · Wi-Fi        │
│                         │
│      [상대 캐릭터]       │  말하면 입이 움직인다
│       크게 가운데         │
│                         │
│   ▁▂▃▅▃▂▁  소리 크기     │
│                         │
│  [방식 바꾸기] [영상]    │
│                         │
│      ((  눌러서 말하기 )) │
│         큰 원형 버튼      │
└─────────────────────────┘
```

캐릭터가 주인공이다. 상대 목소리 크기를 받아 입이 움직인다(T10, T15).

## 테스트

- 누르고 떼는 순서가 꼬여도 **마이크가 켜진 채 남지 않는다** (가장 중요)
- 누른 채로 앱이 뒤로 가면 마이크가 꺼진다
- 잠금이 걸리고 풀린다
- 방식을 바꾸면 상대에게 알림이 간다
- 준비되기 전에 말하면 앞이 잘린다는 것을 확인 (그래서 소리로 알리는 것)
- 항상 열기에서 소리가 없으면 전송이 멈춘다

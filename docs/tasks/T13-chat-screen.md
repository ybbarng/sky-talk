# T13 — 화면: 대화

**단계** 화면 · **상태** 완료 · 실기기 확인 2026-09-19 · **먼저** T06, T09, T12

## 목표

**글로 대화할 수 있다.** 이 카드가 끝나면 앱의 절반은 완성이다.

## 근거

[05-messaging-spec.md](../05-messaging-spec.md) · [07-design-system.md](../07-design-system.md)

## 할 일

```
app/(tabs)/chat.tsx
src/presentation/components/chat/
  MessageList.tsx      거꾸로 흐르는 목록
  MessageBubble.tsx    말풍선
  MessageInput.tsx     입력칸
  DeliveryMark.tsx     보냄/전달됨/읽음 표시
  TypingIndicator.tsx  입력 중
  DayDivider.tsx       날짜 구분선
  SystemNotice.tsx     앱이 끼워 넣는 알림
```

### 목록

- 최신이 아래에 오도록 거꾸로 흐르게 한다
- 50개씩 꺼낸다. 위로 올리면 더 꺼낸다
- 만 건이 있어도 버벅이지 않아야 한다. 화면 밖의 것은 그리지 않는다
- 메시지 높이가 제각각이라 미리 높이를 알 수 없다. 측정한 값을 기억해두고 재사용한다

### 말풍선

- 내 것은 오른쪽 `me` 색, 상대 것은 왼쪽 `peer` 색
- **말하는 쪽 아래 모서리만 각지게** 한다. 꼬리 없이도 어느 쪽인지 안다
- 연달아 온 메시지는 붙여서 보여주고 시각은 마지막에만 적는다
- 새 말풍선은 아래에서 올라오며 나타난다

### 입력칸

- 여러 줄이면 늘어난다. 최대 다섯 줄까지
- 키보드가 올라와도 가려지지 않는다
- 보내기 버튼 옆에 낙서와 콕 찌르기 버튼
- **연결이 끊겨도 입력과 보내기가 막히지 않는다.** 쌓아뒀다가 나중에 보낸다. 대신 "연결되면 보낼게요"라고 알린다

### 전달 상태

```
○  보내는 중
✓  전달됨
✓✓ 읽음
!  실패 — 누르면 다시 보낸다
⏸  대기 중 — 연결되면 자동으로 나간다
```

### 상대 표정

화면 맨 위에 상대 캐릭터를 작게 둔다. T10에서 만든 표정을 그대로 쓴다. 입력 중이면 `typing`, 앱이 뒤로 가 있으면 `sleeping`, 끊기면 `disconnected`다. **글씨를 안 읽어도 상태를 알 수 있다.**

### 읽음 처리

화면에 실제로 보이고 앱이 앞에 있을 때만 읽음으로 친다. 여러 건을 묶어 한 번에 보낸다.

### 알림

앱이 뒤에 있을 때 메시지가 오면 알린다. 기기 안에서 띄우는 알림이라 인터넷이 필요 없다.

## 테스트

- 보낸 메시지가 목록에 즉시 나타난다 (전송 성공을 기다리지 않는다)
- 전송이 실패하면 표시가 바뀌고 다시 보내기가 된다
- 연결이 끊긴 채로 보내면 쌓이고, 붙으면 자동으로 나간다
- 위로 올리면 옛 메시지가 더 나온다
- 만 건에서 넘김이 부드럽다
- 상대 표정이 상태에 맞게 바뀐다

## 하면서 알게 된 것

### 2026-09-19 에 화면에서 고친 것들

실제로 두 폰을 놓고 써보니 시험으로는 못 잡는 것이 줄줄이 나왔다. 전부
[07-design-system.md](../07-design-system.md) 9~10장에 규칙으로 적었다.

- **목록을 뒤집었다(`inverted`).** 도구 줄이나 키보드로 높이가 바뀔 때 보던 자리가
  따라오게 하려고 매번 끝으로 내리던 것이 그림 말풍선과 겹치면 조금씩 못 미쳤다.
  뒤집으면 0번이 바닥이라 계산이 필요 없다. **날짜 구분선은 따로 한 줄**로 뺐다.
  같은 칸에 넣으니 순서가 뒤집혀 말 아래에 떴다.
- **입력칸을 넓혔다.** 도구 단추 넷을 `+` 하나로 접었다. 입력칸이 말풍선 최대 폭과 같다.
- **키보드.** 안드로이드는 edge-to-edge 라 창이 안 줄어든다. 두 폰 다 `behavior="padding"`.
- **머리.** 이름 옆 초록·빨강 점, 밑에는 입력 중·배터리·"N분 전까지 이어져 있었어요",
  오른쪽에 상대 **상태 메시지**. 통화 단추는 뺐다. "연결됨" 글은 점과 겹쳐 뺐다.
- **시각.** 같은 분에 이어 말한 묶음 끝에만. 분이 바뀌면 앞 말에도.
- **비행기 막대.** 비행기가 오른쪽을 향한다. 남은 시간을 누르면 "출발한 지" 로 바뀐다.
  출발·도착 시각을 둘 다 넣을 수 있고 전체 길이가 상대에게도 간다.
- **콕 찌르기 진동.** 햅틱은 아이폰 시스템 설정에 따라 아예 안 울린다. 진동 모터를
  짧게 한 번 돌린다. 설정 → 알림에서 끌 수 있다.
- **음성 메시지.** 누르고 있는 동안 녹음하던 것을 **녹음 창**으로 바꿨다. 눌렸는지
  알 길이 없었고 `expo-audio` 의 `AudioRecorder` 가 맨 위에서 안 나와 조용히 실패하고
  있었다. 최대 20초. 재생은 세모·정지는 네모. 파일이 `.jpg` 로 저장돼 재생이 안 되던
  것도 고쳤다(재생 때 `.m4a` 로 복사).
- **이모티콘 뜻.** 대화 안에서 길게 누르면 옆에 뜻이 뜬다.

### `reanimated` 레이아웃 움직임을 걷어냈다

말풍선이 떠오르는 효과와 설명 창의 `entering` 이 **그려지는 자리와 눌리는 자리를
어긋나게** 했다. 손가락으로 눌러야만 나타나고 시험으로는 안 잡힌다. 전부 뺐다.
`Modal` 은 `Sheet` 하나로 통일했다.

### 끊겨도 입력을 막지 않는다

연결이 없을 때 입력칸을 잠그고 싶어진다. 그러면 **하고 싶은 말을
잊어버린다.** 그대로 쓰게 두고 "연결되면 보낼게요"라고만 알린다.
말풍선에도 같은 표시가 남는다.

### 화면 상태도 줄을 세운다

[T09](./T09-link-manager.md) 에서 만든 `SerialQueue` 를 화면 스토어가
그대로 쓴다. 메시지를 보내는 중에 상대 메시지가 도착하면 같은 문제가
생기기 때문이다. 통합 테스트에서 겪은 것이 실제 화면에서도 똑같이
일어난다.

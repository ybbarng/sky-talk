SkyTalk — 비행기 안의 가상 폰 두 대

인터넷 없는 비행기에서 떨어져 앉은 두 사람이 대화하는 앱이에요. 진짜 앱 코드가 돕니다. 블루투스와 기내 Wi-Fi 를 같이 열어두고 먼저 이어지는 쪽을 쓰고, 한쪽이 끊기면 다른 쪽으로 옮겨 타요. 흉내 내는 건 선·저장소·화면 셋뿐이에요.

바로 연결하기 를 누르거나, 폰 위의 블루투스 를 둘 다 켜보세요. 서로 찾아 붙는 건 앱이 알아서 합니다. 앱에는 그런 버튼이 없어요.
멀어져도 Wi-Fi 로 이어가기 는 블루투스로 이야기하다 자리가 멀어졌을 때 기내 Wi-Fi 로 끊기지 않고 옮겨 타는 것을 보여줘요. 끊겼다 되찾기 는 끊긴 동안 쓴 말이 다시 이어질 때 빠짐없이 건너가는 것을 보여줘요.
손님끼리 막힌 Wi-Fi 를 켜면 Wi-Fi 로는 못 닿아요. 실제 기내 Wi-Fi 에서도 그럴 수 있어요.

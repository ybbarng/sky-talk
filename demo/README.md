# 비행기 안의 가상 폰 두 대

폰이 없어도 **진짜 앱 코드를 그대로 돌려본다.** 블루투스를 켜고, 서로
찾고, 붙고, 인사하고, 말을 주고받고, 자리가 멀어지면 기내 Wi-Fi 로 옮겨
타는 것까지 브라우저 안에서 다 된다.

```bash
pnpm demo                    # 묶고 http://127.0.0.1:8777 로 띄운다
pnpm demo:build              # 묶기만 한다
pnpm demo:publish <폴더>     # 공개용으로 묶어 그 폴더에 내보낸다
```

## 무엇이 진짜인가

`src/` 의 도메인·응용·통신 규약은 순수 TypeScript 라 React Native
없이도 돈다. esbuild 가 그걸 그대로 묶어 가상 기기 두 대에 얹었다.

| 진짜로 도는 것 | 어디 것인가 |
|---|---|
| 두 길을 같이 열고 먼저 이어지는 쪽 쓰기, 끊기면 옮겨 타기 | `CompositeTransport` |
| Wi-Fi 로 상대 찾는 순서(지난 주소 → 게이트웨이 → 가까운 곳부터 훑기) | `planDiscovery` · `scanTargets` |
| 다시 찾는 간격 | `retryDelayMillis` |
| 보내기·받기·재전송 | `src/application/messaging/` |
| 놓친 말 되찾기 | `ConversationSync` |
| 읽음·전달 표시 | `MarkAsRead`, `ack`/`read` 봉투 |
| 봉투 만들고 읽기 | `encodeEnvelope` / `FrameDecoder` |
| 화면 단계 판단, 도움말 띄울 때 | `decidePhase` · `shouldShowHint` |
| 안내 문구 | `copyFor` · `longHintFor` |
| 색·캐릭터 | `theme/colors.ts`, `characters/` 와 같은 값 |

로그 창에 뜨는 바이트 수는 **실제로 만들어진 봉투 크기**다. 지어낸
숫자가 아니다.

## 흉내 내는 것 셋

- **선** — 블루투스·Wi-Fi 대신 브라우저 안(`demo/src/world.ts`)에서
  바이트를 나른다. 블루투스는 둘 다 켜고 가까이 앉아야, Wi-Fi 는 둘 다
  붙고 손님끼리 막힌 망이 아니어야 닿는다. 블루투스는 좁아서 큰 봉투일수록
  늦게 간다. 어느 길이든 **보낸 순서대로 닿는다**
- **저장소** — SQLite 대신 메모리(`demo/src/MemoryRepository.ts`).
  `ConversationRepository` 를 그대로 구현한다
- **화면** — React Native 대신 HTML

앱의 각 길(`BleMessageTransport`, `WifiLink`) 자리에는 `DemoLink` 가
꽂힌다. 찾는 데 드는 시간과 선만 흉내 내고, 찾는 쪽은 아이폰뿐이고 받는
쪽 Wi-Fi 는 첫 봉투가 와야 상대로 치는 것까지 앱과 같게 둔다.

## 해보기

**바로 연결하기** 를 누르거나 폰 위의 **블루투스** 를 둘 다 켠다.

**서로 찾아 붙는 버튼은 없다.** 앱에 그런 버튼이 없기 때문이다.
앱을 연 순간 두 길을 같이 열고 각자 알아서 계속 찾는다. 사람이 누르는
것은 블루투스, 기내 Wi-Fi, 자리뿐이다.

- **멀어져도 Wi-Fi 로 이어가기** — 블루투스로 이야기하다 둘 다 기내
  Wi-Fi 에 붙고, 멀리 떨어져 앉는다. 블루투스가 끊기는 순간 이미 이어져
  있던 Wi-Fi 로 옮겨 타고, 새 길로 다시 인사한다
- **끊겼다 되찾기** — 블루투스도 Wi-Fi 도 끊긴 동안 양쪽이 글을 쓰고,
  다시 가까이 앉는다. 놓친 말이 `sync_response` 로 건너온다
- **손님끼리 막힌 Wi-Fi** — 같은 Wi-Fi 에 붙어도 못 닿는다. 아이폰이
  끝까지 훑고 1, 2, 4초 … 쉬었다 다시 찾는 것을 기록에서 본다. 20초가
  넘으면 화면에 도움말이 뜬다
- **바이트 쪼개기** — 봉투를 잘라 보낸다. `FrameDecoder` 가 이어 붙이는지 본다
- **느린 선** — 선을 여덟 배 느리게 한다
- **밝은 화면** — 두 벌의 색을 바꿔 본다

이모티콘은 **길게 누르면 무슨 말인지** 위에 뜬다. Wi-Fi 로 이어져 있을
때만 `typing` 이 건너간다. 앱이 좁은 블루투스에서는 아끼기 때문이다.

## 공개 페이지

https://gh.byb.kr/sky-talk/ 에 있다. `main` 에 올라오면
`.github/workflows/demo-pages.yml` 이 `pnpm verify` 를 돌리고
`pnpm demo:publish site` 로 묶어 GitHub Pages 에 올린다. dev.byb.kr 허브는
여기와 저장소를 가리키기만 한다. **고칠 곳은 이 저장소 하나다.**

**공개용에는 `.env` 를 읽지 않는다.** 핫스팟 비밀번호가 묶음에 박혀
그대로 공개되기 때문이다. 압축하고, 맨 위에 "직접 고치지 말 것" 과 허브·
저장소로 가는 링크를 단다.

## 폰 두 대가 달라 보이는 것

**앱이 그리는 것은 두 폰이 똑같다.** React Native 한 벌이라 말풍선도
머리도 입력줄도 같다. 모서리를 몇 픽셀로 깎을지는 앱이 정하지
운영체제가 정하지 않는다.

다른 것은 **앱이 못 건드리는 것들**뿐이다.

| | 안드로이드 | 아이폰 |
|---|---|---|
| 모서리 | 덜 둥글다 | 크게 둥글다 |
| 위쪽 | 카메라 구멍 | 알약 |
| 아래쪽 | 세 칸짜리 막대 | 손잡이 하나 |
| 배터리 | 세로로 선다 | 가로로 눕는다 |
| 기본 글꼴 | Roboto | San Francisco |

## 폰 밖에 있는 것

가운데 창은 앱에 없다. 가상 망에서 실제로 오간 봉투와, 진짜
`decidePhase` 가 고른 단계(`need-hotspot` 같은)와 두 길이 각각 이어졌는지를
적어둔다.
**폰 화면 안에는 그런 영어가 뜨지 않는다.**

## 여기 없는 것

통화·사진·낙서는 카메라와 마이크가 있어야 해서 뺐다. 그건
`pnpm test` 가 확인한다.

`biome` 검사에서는 뺐다. 앱에 들어가는 코드가 아니라 브라우저에서만
도는 껍데기라 규칙이 다르다. `demo/app.js` 는 묶은 결과물이다.
